KEY FEATURES:
-------------

1. FORGOT PASSWORD
   - Request password reset via email
   - Secure token generation (nanoid, 32 chars)
   - Token expiry: 1 hour
   - Single-use tokens
   - Password reset form with validation
   - Success/error toast notifications

2. EMAIL VERIFICATION
   - Automatic token generation on registration
   - Email verification required for credential login
   - Token expiry: 24 hours
   - Resend verification email option
   - Warning message for unverified users
   - Automatic verification via link

3. GOOGLE OAUTH
   - Configured in NextAuth
   - Auto-registration for new users
   - Auto-verification of email
   - Role assignment (default: user)
   - Session management

4. GITHUB OAUTH
   - Configured in NextAuth
   - Auto-registration for new users
   - Auto-verification of email
   - Role assignment (default: user)
   - Session management

CONFIGURATION REQUIRED:
-----------------------
To use OAuth providers, configure these environment variables:

  AUTH_GOOGLE_ID=your_google_client_id
  AUTH_GOOGLE_SECRET=your_google_client_secret
  AUTH_GITHUB_ID=your_github_client_id
  AUTH_GITHUB_SECRET=your_github_client_secret
  AUTH_SECRET=your_secure_random_string

OAuth Setup:
  Google: https://console.cloud.google.com/
  GitHub: https://github.com/settings/developers

USAGE:
------

Forgot Password:
  1. Navigate to /forgot-password
  2. Enter email address
  3. Check console for reset token
  4. Navigate to /reset-password?token=<token>
  5. Enter new password
  6. Login with new password

Email Verification:
  1. Register new account
  2. Check console for verification token
  3. Click verification link or navigate to /verify-email?token=<token>
  4. Email will be marked as verified
  5. Login with credentials

OAuth Sign-In:
  1. Click Google or GitHub button on login page
  2. Complete OAuth flow
  3. User will be created/verified automatically
  4. Redirected to dashboard
